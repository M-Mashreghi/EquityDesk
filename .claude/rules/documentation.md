# Documentation Rules

## Language

Repository documentation and code comments are English.

## SSOT

`docs/PROJECT_PHASES_AND_TASKS.md` is the atomic delivery source of truth.

`docs/TASKS.md` is the progress ledger.

## Synchronization

After a task changes behavior, update the relevant:

- task status / verification log
- architecture contract
- configuration keys
- Mermaid diagrams
- deployment/runbook steps

Do not mark a task complete before documentation is synchronized.

## Research Contracts

Changes to source hierarchy, point-in-time rules, financial formulas, citation rules, valuation methods, or report schema must be documented explicitly.
